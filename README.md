
# Números Ímpares em Python

Projeto desenvolvido durante meus estudos de Python, com foco na criação de funções, manipulação de listas e uso de estruturas condicionais e de repetição.

O programa recebe uma lista de números e utiliza uma função para identificar e retornar apenas os números ímpares.

### Conceitos praticados

* Funções em Python
* Parâmetros e `return`
* Listas
* Estrutura `for`
* Estrutura condicional `if`
* Operador `%` (módulo)
* Método `append()`

### Exemplo

Entrada:
[2, 7, 8, 11, 14, 20, 5]


Saída:
[7, 11, 5]

Este projeto faz parte da minha prática contínua de **lógica de programação com Python**.
